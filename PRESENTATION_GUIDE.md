# Presentation Materials

## 1. Demo Script (5 to 7 minutes)
1. **Intro (30 s):** "Good day. My website is *Discover Cebu City*, a tourism site under Category 3."
2. **Folder (30 s):** Show the folder: 12 HTML files, styles.css, images folder.
3. **Home page (1 min):** Show navbar, dropdowns, hero, cards. Open in VS Code and point to `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`.
4. **Navigation (1 min):** Click every menu item. Show the same nav on all pages. Open Sitemap.
5. **Elements (2 min):** Show a table (festivals.html), ordered list (about.html), unordered list (attractions.html), image with `alt` (gallery.html).
6. **Links and testing (1 min):** Explain relative links like `<a href="food.html">`.
7. **Closing (30 s):** Challenges and what you learned.

## 4. Guide Questions: Sample Answers
1. **Purpose?** To inform and attract visitors to Cebu City.
2. **Why this category?** I live in the Visayas and Cebu has rich history, food, and festivals.
3. **Basic HTML structure?** `<!DOCTYPE html>`, then `<html>` containing `<head>` (title, meta, link) and `<body>` (visible content).
4. **How connected?** With `<a href="page.html">` in a shared navigation on every page.
5. **Most used tags?** `<a>`, `<p>`, `<h1>` to `<h3>`, `<li>`, `<img>`, `<td>`.
6. **Images, lists, tables?** `<img src="images/x.svg" alt="...">`; `<ul>`/`<ol>` with `<li>`; `<table>` with `<tr>`, `<th>`, `<td>`.
7. **Challenges?** Broken paths, repeated navigation, dropdown menu. Fixed by testing and using relative paths.
8. **Testing?** Opened each page, clicked every link, checked images, and fixed errors.

## 5. Quick tags to explain if asked
- `alt`: text shown if the image fails; helps screen readers.
- `href`: destination of a link. `src`: location of an image.
- `rel="noopener"` with `target="_blank"`: safer links to outside sites.
- `<link rel="stylesheet">`: connects the CSS file.
